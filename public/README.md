# 素材放置指南 (Asset Setup)

請將以下檔案放入對應資料夾，遊戲才能顯示真實圖片與音效。
在素材放入前，遊戲會自動顯示佔位符（仍可完整遊玩）。

## images/ 資料夾

### 背景
- `封面背景.PNG` — 首頁背景
- `遊戲背景.PNG` — 主養成區背景
- `扭蛋背景.PNG` — 扭蛋區背景
- `花園背景.PNG` — 退休花園背景

### 介面按鍵
- `設定按鍵.PNG` / `圖鑑按鍵.PNG` / `升級按鍵.PNG`
- `食物按鍵.PNG` / `扭蛋按鍵.PNG` / `花園按鍵.PNG` / `退出遊戲按鍵.PNG`
- `封面開始按鍵.PNG` — 開始按鈕

### 版面（彈窗背景）
- `設定版面.PNG` / `圖鑑版面.PNG` / `升級版面.PNG` / `食物版面.PNG`

### 扭蛋相關
- `扭蛋機.PNG` / `扭蛋.PNG` / `抽取扭蛋畫面.PNG`

### 開關圖示
- `背景音樂 on.PNG` / `背景音樂 off.PNG`
- `音效 on.PNG` / `音效 off.PNG`

### 道具
- `蛋.PNG` / `蘋果.PNG`

### 蛇角色（6 種 × 3 階段 × 2 狀態 + 剪影）
青草蛇、草莓蛇、天空蛇、海蛇、地頭蛇、Python蛇，
每種需準備：幼年、幼年蛇被摸、青年、青年蛇被摸、成蛇、成蛇被摸、剪影。
完整檔名請見 `src/game/snakes.ts`。

## audio/ 資料夾
- `封面背景音樂.m4a` — 首頁 BGM
- `遊戲背景音樂.m4a` — 主畫面 BGM
- `扭蛋抽取音樂.m4a` — 扭蛋區 BGM
- `按鍵音效.m4a` — 按鍵點擊
- `蛇幼年聲.m4a` / `青年蛇聲.m4a` / `成年蛇聲.m4a` — 蛇叫聲
- `扭蛋抽取聲.m4a` / `扭蛋掉出音效.m4a` — 扭蛋音效
